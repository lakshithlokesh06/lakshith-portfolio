# Lakshith S Lokesh — Portfolio

Professional portfolio website for Lakshith S Lokesh, a Data Science & Machine Learning Developer.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion

## Features

- Responsive professional portfolio
- Featured project case studies
- Real GitHub and live-demo links
- Resume integration
- Project screenshots
- SEO metadata
- Sitemap and robots configuration
- Responsive mobile navigation

## Local Development

```bash
npm install
npm run dev
```

## Production Validation

```bash
npm run lint
npm run build
```

## Deployment

The portfolio is prepared for deployment on Vercel.
